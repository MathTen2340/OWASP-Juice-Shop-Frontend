# OWASP-Juice-Shop-Frontend

## About:
A login page with a identical client-side and server-side validation with login checks for valid email, password length, and empty fields.

## Running Application:
1. Make sure node.js is installed.
2. Run: node server.js
3. Go to: http://localhost:3000

## Frontend:
Built with html and javascript

## Files:
index.html - contains the frontend code to display the login page as well as the Client-side script
server.js - contains an HTTP server that routes login information from client-side to server-side and validates whether login is successful or not
